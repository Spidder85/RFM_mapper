## 1.1.  Описание электронного сервиса

Электронный сервис «Сервисный концентратор Росфинмониторинга» предоставляет возможность пользователям Личного кабинета на официальном сайте Росфинмониторинга направлять в Федеральную службу по финансовому мониторингу и получать сведения в рамках, существующих НПА.

*Табл. 2 Описание электронного сервиса*

## 2.2.  Установление https-соединения

При вызове любого метода сервиса для установления защищенного по ГОСТ https-соединения необходимо передавать сведения о сертификате инициатора запроса (тот же сертификат, который используется для входа в защищенный Личный кабинет на официальном сайте Росфинмониторинга).

Например, на языке программирования C# это будет выглядеть следующим образом:
```C#
public HttpClient CreateHttpClient(X509Certificate2 cert) {
    var hendler = new WebRequestHandler();
    hendler.ClientCertificates.Add(cert);
    return new HttpClient(hendler)
}
```

## 3.1.  Порядок получения доступа к тестовым методам электронного сервиса

Для получения доступа к интересующим тестовым методам необходимо через свой Личный кабинет на официальном сайте Росфинмониторинга направить заявку в техническую поддержку, указав в поле Тематика обращения «Сервисный концентратор», а в тексте указать: «Регламентная процедура. Получение доступа к тестовым методам ЭС».

# 3.2.  Порядок получения доступа к продуктивным методам электронного сервиса

Для получения доступа к продуктивным методам электронного сервиса «Сервисный концентратор Росфинмониторинга» (далее – ЭС) необходимо:

1.  Успешно пройти тестирование, вызвав **все тестовые методы ЭС**;
2.  Заполнить форму заявки на получение доступа к продуктивным методам ЭС и вместе с неформатированными конвертами запросов-ответов (требуются только те запросы и ответы, которые содержат параметры) к тестовым методам ЭС в формате JSON упаковать в zip-архив. **Прикладывать конверт запрос-ответа метода authenticate не требуется**;
3.  Сформированный архив направить в Росфинмониторинг, _заполнив заявку в техническую поддержку и указать в Тематике обращения: «Сервисный концентратор», а в тексте заявки: «Регламентная процедура. Получение доступа к продуктивным методам ЭС_».
